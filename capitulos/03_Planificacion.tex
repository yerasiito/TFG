\chapter{Planificación} \label{planificacion}
Para gestionar la planificación del proyecto, se ha implementado el método Kanban para organizar y asignar tareas de manera eficiente, utilizando la herramienta Wakatime para registrar y analizar el tiempo invertido en cada actividad. Esta metodología permite un seguimiento preciso de las tareas completadas y del esfuerzo dedicado, asegurando así el cumplimiento de los objetivos semanales en un periodo de seis semanas. La planificación ha resultado fundamental para equilibrar el desarrollo del trabajo de fin de grado junto con las prácticas en la empresa, en las cuales dedico cinco horas diarias de trabajo durante la semana, dejando las tardes de entre semana y el fin de semana como el principal período de dedicación al proyecto académico.

\section{Planificación semanal}
Dado el tiempo total de un mes y medio para la realización del proyecto, la planificación se ha organizado de la siguiente manera:

\begin{itemize}
    \item \textbf{Primera semana}: documentación y análisis del estado del proyecto.
    \item \textbf{Segunda semana}: resolución de deuda técnica.
    \item \textbf{Tercera semana}: desarrollo de la interfaz de usuario.
    \item \textbf{Cuarta y quinta semana}: redacción de la memoria.
    \item \textbf{Sexta semana}: incorporación de funcionalidades adicionales y tests al proyecto, así como finalización de documentación y ajustes finales.
\end{itemize}
Cada sección semanal incluirá:
\begin{itemize}
    \item Lista de tareas (Kanban)
    \item Registro de tiempo (Wakatime)
    \item Literatura y referencias empleadas
    \item Commits de github (si aplica)
\end{itemize}
